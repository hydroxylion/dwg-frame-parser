# dwg-frame-parser（DWG/DXF 图框解析工具）

> 技术栈：Flask + ezdxf + 原生 JS（前端）

上传 DXF/DWG 图纸，后端智能识别图框并返回宽×高（mm）、图框数量及候选明细。

---

## 一、图框识别算法（核心流程）

### 1. 候选收集（模型空间 + 所有布局空间）

| 候选来源 | 说明 |
| --- | --- |
| 闭合多段线 | LWPOLYLINE/POLYLINE，含矩形度过滤（≥0.92，剔除 L 形标题栏等） |
| INSERT 块参照 | 块定义 bbox × xscale/yscale + rotation + insert 点 = 真实图框 bbox；预筛短边 ≥500mm（**或命中标准 A 系列短边 210/297/420…**，A4 等小块图框块可入库）且长宽比 ∈[1.05, 5.5] |
| 直线矩形 | 共线聚合 + 线对配对 + P1 严格矩形判定（4 边各有完整 LINE 覆盖）；密集聚类时**长边（跨度≥180）全配对**找回远距离图框边界，线对按公共覆盖长度排序；组合扫描按**竖对 x 起点落在横线公共覆盖段内（xa∈[xLo,xHi] 且 xb≤xHi）、xa 升序**遍历——帧左边界对排最前命中即确认，坐标直接排除大量无效竖对，杜绝高密度图（数万线对）预算耗尽漏检 |
| 全实体包围盒（降级） | 以上全无时兜底；**排除 VIEWPORT 与文字/标注类实体**（TEXT/MTEXT/DIMENSION 等——文字允许外溢，不撑宽图框） |

**坐标处理**：
- 实体坐标统一 **OCS→WCS** 转换（`get_polyline_vertices`/LINE 端点经 `ocs().to_wcs()`），兼容带倾斜 extrusion 的实体
- **全局旋转矫正**：自定义 UCS 整体倾斜的图纸（实体坐标斜存 WCS），按长度加权直方图估计主方向，主体共旋占比 ≥65% 才施加旋转矩阵"转正"（防混合方向图纸误转），使矩形度 / 水平垂直检测恢复有效

**可见性过滤**（收集前）：跳过冻结/隐藏图层实体 + 实体级 invisible（组码 60），只统计 CAD 里可见的实体。

### 2. 图框特征匹配（is_frame_like，按序判定）

- **前置**：归一化长宽比 ∈ [1.05, 5.5]；`area_ratio > 1.0 + 0.1%`（候选面积超过 layout 总面积，含浮点容差）直接判异常剔除
- **条件 A**：面积占比 ≥ 15%（常规单图框 layout）
- **条件 C**：相对面积 ≥ 该 layout 最大候选面积 × 10% **且 √2 ≤ 长宽比 ≤ 2.5**（多图框同 layout / 非标单位；≥√2 允许 A 系列加长版、过滤接近正方形的建筑外框；≤2.5 剔除细长内容块 bbox 冒充图框）
- **条件 B**：显式矩形 + 短边 ∈[400, 2000]mm + 宽高接近整数 + 长宽比接近 √2±10%（密集几何场景，过滤家具/设备小矩形）；**直线矩形类型额外要求相对面积 ≥10%**（过滤 CAD 远处残留几何框）
- **条件 D**：同 layout **同尺寸直线矩形 ≥2 份** + 长宽比接近 √2±10% + 短边 ≥500 + 相对面积 ≥1%（多尺度"套图"里小页框面积远小于最大图框仍可识别；rel≥1% 排除重复表格/阵列矩形）

### 3. 候选清洗（匹配通过后）

1. **包裹框剔除**：内部完全包含 ≥2 个独立尺寸图框候选的大框判为外包络剔除（按 5% 尺寸聚类去重，避免同图框重复画法误剔；单尺寸组实例 ≥3 也判为拼版外框；跳过 INSERT 块参照）
2. **对齐排列剔除**：同块名 ≥3 个 INSERT 实例短方向紧贴成线判为装饰块（柱网/门窗阵列）；**标准 A 系列尺寸白名单**保护（短边 ∈{841,594,420,297,210,148,105} 且长边 ≈ 短边×√2 不参与剔除）
3. **去重**：嵌套（面积 < 外框 95%）+ IoU > 50%
4. **模型空间降级框清洗**：布局空间已识别真图框时，剔除模型空间的"全实体包围盒"（模型空间仅是内容区）
5. **每 layout 上限 100**（防爆炸兜底）

### 4. XREF 外部参照警告

ezdxf 默认不加载 XREF 外部文件，引用块会漏识别图框。检测到时写日志警告（不阻塞解析），API 返回 `xref_warnings` 字段供前端展示。

### 5. 输出

- `width` / `height`：选中图框尺寸（面积最大候选，可按优先级加权）
- `frame_count`：图框数量
- `candidates`：候选明细（前 20）
- `xref_warnings`：XREF 警告列表

## 三、优化记录

### 2026-09-04

- **实体坐标 OCS→WCS 统一转换**：`get_polyline_vertices` / LINE 端点经 `ocs().to_wcs()`，兼容带倾斜 extrusion 的实体
- **全局旋转矫正（UCS 图纸）**：长度加权直方图估计主方向 + 主体共旋 ≥65% 门限（防混合方向图纸误转），把倾斜图框"转正"后识别（如 A3 297×420 图框不再被矩形度门槛误杀）
- **直线矩形长边全配对**：密集聚类（>16）时对跨度 ≥300 的图框级长边聚类两两全配对 + 相邻配对双通道，线对按间距降序避免被组合上限截断（机械图纸多图框漏检修复）
- **前端记录表加宽 + 批量操作**：整体宽度拉大、列不换行信息一眼看全；新增全选/行勾选与批量删除
- **图框数可截图气泡**：自绘固定气泡（原生 title 无法截图），悬停弹出/移开保留/可固定常显；完整列出所有图框（超 20 可滚动）、同尺寸聚合为 `宽×高 ×n`、一键复制全部

**同日补充（第二轮）**：
- **直线矩形检测配对重构**：线对预过滤（公共覆盖过短丢弃）+ 按公共覆盖长度排序 + 宽高比例剪枝与右界截断、预算提至 50 万——密集图纸海量"超远装饰线对"不再抢占预算，LINE 双层封面框（28261×19985）可召回；长边配对阈值 300→180，A4/A3 及 280×195 等短边<300 的 LINE 图框不再漏检
- **特征/包裹规则加固**：直线矩形额外要求相对面积 ≥10%（CAD 远处残留矩形过滤）；area_ratio 异常过滤加 0.1% 浮点容差（图框即 layout 最大外框时不再误杀）；包裹剔除单尺寸组实例 ≥3 判拼版外框
- **全实体包围盒降级修正**：降级只统计绘图几何实体、排除 TEXT/MTEXT/DIMENSION 等（文字外溢不再撑宽图框）；布局空间已识别真图框时剔除模型空间降级框（机械图"模型空间画内容、布局放图框"结构）
- **DWG 转换 ODA audit 兜底**：ODA 默认转换产物截断（缺 ENDSEC）的 DWG 自动以 audit=True 重试
- **INSERT 预筛 A 系放行**：短边命中标准 A 系列（210/297/420…）的小块图框可入库（A4 块图框不再被家具过滤误杀）
- **前端"混合"分类**：逐框分类统计，标准族与非标族并存的文件加 🌀混合 徽标（悬浮显示构成），筛选栏新增"混合"维度，不破坏现有 4 类

**同日补充（第三轮）**：
- **LINE 矩形组合扫描坐标包含遍历**：竖对按 x 起点落在横线公共覆盖段内升序扫描（帧左边界对排最前），替代"gap 全窗口"遍历——数万线对的高密度图纸不再因预算耗尽漏检帧（电子称皮带输送系统 6→10，图层 0 LINE 页框 21475×30372×1 + 29788×21062×3 + 14894×10531×2 全部召回）；候选上限提至 5000
- **条件C 长宽比 ≤2.5 上限**：剔除内容块 bbox 冒充图框（A$C67EE090B 127686×34157 ratio 3.74 靠 rel 80% 误收）；真图纸页框比例通常 ≤2.1
- **条件D（同尺寸重复页框通道）**：同 layout 同尺寸直线矩形 ≥2 份 + √2±10% + 短边 ≥500 + rel ≥1% 即收——多尺度套图中小页框面积远小于最大图框（rel 2.9%）仍可识别；rel≥1% 挡掉成批重复的表格/阵列矩形

### 2026-09-03

- **包裹框识别 + 条件C 相对面积法 + 可见性过滤**：外层大框内含 ≥2 个独立尺寸图框候选判为外包络剔除；相对面积法适配多图框同 layout 与非标单位；冻结图层/实体级 invisible 过滤
- **INSERT 块参照路径 + 对齐排列剔除**：块参照插入是图框常见画法，补全识别路径；同块名对齐排列实例判为装饰块剔除

- **空布局视口过滤**：降级路径排除 VIEWPORT，仅含视口的空布局不产生伪图框

## 四、API

`POST /upload`（multipart/form-data）

| 参数 | 说明 |
| --- | --- |
| file | .dxf / .dwg 文件 |
| priority | polyline（默认）/ line_rect |
| unit | mm（默认）/ inch |
| mode | smart（默认）/ force_max |

返回：`{ width, height, unit, frame_count, candidates[], xref_warnings[] }`

## 五、本地运行

```
pip install -r requirements.txt
python app.py
```

启动后访问 `http://127.0.0.1:5000`。`.dwg` 解析依赖 [ODA File Converter](https://www.opendesign.com/guestfiles/oda_file_converter)，需本机安装并保持默认路径；`.dxf` 可直接解析。
