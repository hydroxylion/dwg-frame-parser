dwg-frame-parser 图框识别技术文档

技术栈：Python / Flask · ezdxf 1.4 · ODA File Converter（DWG→DXF）· matplotlib（渲染核对）｜文档对应版本：第二十六轮（R26）

一句话概述：对 DWG/DXF 施工图逐布局收集图框候选（闭合多段线 / INSERT 块参照 / 直线组合 / 包围盒降级），经特征筛选（条件 A~I + 救援通道）与三级后处理（包裹剔除 → 去重 → 附栏外扩）输出图框清单（frame_count / best / candidates）；配套「规则单测 → 回归基线 → 渲染叠加核对」三层校验闭环。

三、关键设计规则速查

规则（轮次）场景与判据
组合预算剪枝（R22）直线矩形通道组合数爆炸（百万级线对）耗尽预算 → 长边全配降级 + 竖对覆盖必要条件剪枝，真实框线对进入可达范围
斜放块去旋转口径（R25）INSERT 旋转非 90° 倍数：bbox 是旋转外接矩形（面积/ratio 失真）→ 尺寸改用「块定义×缩放」真实图幅，bbox 保留作空间关系；打 tilted 标记
同尺寸错排豁免（R25）去重规则2：宽高一致（2% 容差、含互换）且中心偏移 ≥5% → 两张独立错排图，IoU>50% 也不剔
tilted 不作嵌套 outer（R25）斜放块 bbox「包含」≠真实包含（真实足迹是斜带），防止误剔 bbox 角落的邻位真框
内容块剔除（R26）块定义内最长直边构件（LINE/LWPOLYLINE 边段/闭合 bbox/嵌套子块，递归含缩放）< 块长边×30% → bbox 系稀疏散件撑出的「假图框」，不入候选库（典型：天正代理实体 + 辅助小方块，最长边仅块长边 0.19%）
附栏外扩（R23）横版主框（短边≥50000 且宽<95000）左/右 2000~22000 邻位存在同排同规格图纸的图签条 → 外扩 21000 合并输出（105100 口径）
